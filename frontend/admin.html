Admin Bilgilendirme

Bu bölüm paneldeki ceza ve moderasyon terimlerini sade şekilde açıklar.

Mute

Mute, kullanıcının belirli süre mesaj/gönderi gibi etkileşimleri yapmasının engellenmesidir. Hesap silinmez, süre bitince tekrar kullanabilir.

Ban

Ban, kullanıcının uygulamaya erişiminin kapatılmasıdır. Ağır veya tekrarlayan ihlallerde kullanılmalıdır.

Rapor / Şikayet

Açık rapor admin tarafından incelenmemiştir. Problem çözüldü olarak işaretlenince rapor kapanır ve ilgili öğrencilere bildirim gider.

Argo / Yasaklı Kelime

Kullanıcı argo kelime yazarsa metin otomatik sansürlenir ve kullanıcıya uyarı bildirimi gider. Tekrar ederse admin paneline bildirim düşer; admin mute, ban veya sadece takip kararı verebilir.

Admin Şifre Ayarı

Admin şifresinin kaç ayda bir yenilenmesi gerektiğini seç. 1, 3 veya 6 ay seçilebilir.

Aranamaz seçilirse kullanıcılar admin hesabına sesli/görüntülü arama başlatamaz.

Açılırsa kullanıcıların admin hesabına gönderdiği DM mesajları bildirim düşürmez.
